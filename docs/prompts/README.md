# Prompts

Ad-hoc prompts used for system auditing, testing, and quality validation. Paste these into a Claude conversation to run audits or validate system behavior.

| Prompt | Purpose |
|--------|---------|
| `system-audit-prompts.md` | General system audit checks |
| `e2e-report-test.md` | End-to-end report generation test |
| `sample-report-validation.md` | Validate sample report output quality |
| `analyze-automation-recommendations.md` | Audit automation recommendation quality |
| `analyze-vendor-system.md` | Audit vendor database and matching |
| `audit-insights-system.md` | Audit curated insights system |
| `improve-4-option-recommendations.md` | Improve the four-option recommendation format |
| `vendor-research-prompt.md` | Prompt for vendor discovery/research |
