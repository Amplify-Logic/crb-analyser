The CRB NET Score formula:

```
NET SCORE = Total Benefit - Total Cost - (Total Risk / 10)
```

Where:
- **Benefit** = Financial + Time + Strategic + Quality (confidence-adjusted)
- **Cost** = Financial + Time + Opportunity + Complexity + Risk + Brand/Trust
- **Risk** = Sum of (Probability x Impact) across Technical, Adoption, Vendor, and Market risks
