# ReadyPath API

The ReadyPath API provides programmatic access to our AI-powered Cost-Risk-Benefit analysis platform. Use it to integrate CRB assessments into your own workflows, automate report generation, or build custom experiences on top of our analysis engine.

## Base URL

```
https://api.readypath.ai/api
```

## Response Format

All endpoints return JSON:

```json
{
  "status": "success",
  "data": { ... },
  "meta": {
    "request_id": "req_abc123",
    "timestamp": "2026-02-21T10:30:00Z"
  }
}
```

Error responses follow a consistent format:

```json
{
  "status": "error",
  "error": {
    "code": "NOT_FOUND",
    "message": "Report not found",
    "details": {}
  }
}
```

## SDKs

<Tabs>
  <Tab title="Python">
    ```bash
    pip install readypath
    ```
    ```python
    from readypath import ReadyPathClient

    client = ReadyPathClient(api_key="your-api-key")
    session = client.quiz.create(industry="professional-services")
    ```
  </Tab>
  <Tab title="JavaScript">
    ```bash
    npm install @readypath/sdk
    ```
    ```javascript
    import { ReadyPathClient } from '@readypath/sdk';

    const client = new ReadyPathClient({ apiKey: 'your-api-key' });
    const session = await client.quiz.create({ industry: 'professional-services' });
    ```
  </Tab>
</Tabs>
