# Authentication

The ReadyPath API uses API keys for server-to-server authentication and JWT tokens for client-side access.

## API Keys

Include your API key in the `Authorization` header:

```bash
curl -H "Authorization: Bearer YOUR_API_KEY" \
  https://api.readypath.ai/api/reports
```

### Getting an API Key

1. Sign in to your [ReadyPath dashboard](https://readypath.ai/dashboard)
2. Navigate to **Settings > API Keys**
3. Click **Generate New Key**
4. Copy and store the key securely — it's only shown once

### Key Security

<Warning>
  Never expose your API key in client-side code, public repositories, or browser requests. Use environment variables and server-side calls only.
</Warning>

- Rotate keys regularly
- Use separate keys for development and production
- Revoke compromised keys immediately from the dashboard

## JWT Authentication

For client-side applications, use the Supabase authentication flow:

```javascript
// Sign in and get a session token
const { data, error } = await supabase.auth.signInWithPassword({
  email: 'user@example.com',
  password: 'password'
});

// Use the access token for API calls
const response = await fetch('https://api.readypath.ai/api/reports', {
  headers: {
    'Authorization': `Bearer ${data.session.access_token}`
  }
});
```

## Permissions

| Scope | Access |
|-------|--------|
| `quiz:read` | Read quiz sessions |
| `quiz:write` | Create and modify quiz sessions |
| `reports:read` | Read reports |
| `reports:generate` | Trigger report generation |
| `vendors:read` | Read vendor data |
