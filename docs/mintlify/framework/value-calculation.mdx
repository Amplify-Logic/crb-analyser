# Value Calculation Methodology

CRB separates value into two distinct types to capture the full picture.

## Value Saved (Efficiency)

Value recovered by doing existing work more efficiently.

### Formula

```
Value Saved = Time Saved per Task x Cost per Hour x Tasks per Period x 52 weeks
```

### Example: Automating Client Onboarding

| Variable | Value |
|----------|-------|
| Current time per onboarding | 4 hours |
| Time with automation | 1 hour |
| Time saved | 3 hours |
| Cost per hour (blended) | EUR 55 |
| Onboardings per week | 5 |
| **Annual Value Saved** | **EUR 42,900** |

### What Counts as Value Saved

- Reduced manual data entry
- Automated report generation
- Streamlined approval workflows
- Eliminated duplicate systems
- Faster search and retrieval

## Value Created (Growth)

New value generated that didn't exist before.

### Components

| Component | How Measured |
|-----------|-------------|
| **Conversion improvement** | Additional revenue from higher conversion rates |
| **Customer lifetime value** | Revenue from improved retention |
| **New service lines** | Revenue from capabilities the technology enables |
| **Time-to-market** | Revenue from launching products/services faster |
| **Competitive wins** | Revenue from deals won due to better capabilities |

### Example: AI-Powered Client Insights

| Component | Projected Value |
|-----------|----------------|
| 5% conversion improvement (EUR 500K base) | EUR 25,000 |
| 10% retention improvement (EUR 200 LTV increase x 100 clients) | EUR 20,000 |
| New "AI Audit" service line | EUR 30,000 |
| **Annual Value Created** | **EUR 75,000** |

## Combined Value

```
Total Value = Value Saved + Value Created
```

In the examples above:
- Value Saved: EUR 42,900
- Value Created: EUR 75,000
- **Total Value: EUR 117,900**

This feeds into the NET Score as the "Benefit" component.

## Confidence Adjustment

All projections are adjusted by confidence:

```
Adjusted Value = Raw Value x Confidence Factor
```

| Confidence | Factor | When Applied |
|------------|--------|-------------|
| High (1.0) | 100% | Verified data, proven benchmarks |
| Medium (0.85) | 85% | Industry estimates, comparable cases |
| Low (0.70) | 70% | Extrapolated, limited data |

### Applied to Our Example

| | Raw | Confidence | Adjusted |
|-|-----|-----------|----------|
| Value Saved | EUR 42,900 | High (1.0) | EUR 42,900 |
| Value Created | EUR 75,000 | Medium (0.85) | EUR 63,750 |
| **Total** | **EUR 117,900** | | **EUR 106,650** |

<Tip>
  CRB reports always use the confidence-adjusted figure for NET score calculations. This ensures recommendations are conservative and achievable rather than aspirational.
</Tip>
