# PART 2: The 90-Minute Workshop

> Paid session. 3 phases. Voice or text input. AI-adaptive conversation.

---

## Phase 1 - Confirmation (~15 min)

*"Did we understand you correctly?"*

The system presents **4 confirmation cards** built from quiz answers and pre-research. The user reviews each one:

All cards must be rated before moving on.

## Phase 2 - Deep-Dive (~60 min)

*"Let's explore each pain point in detail"*

For each pain point (2-4 typically), the AI walks through **5 conversation stages**.
Questions are generated dynamically - one at a time, conversational, probing for specifics.

### How the AI Adapts

The AI detects user signals and adjusts its approach:

| Signal Detected | AI Adjusts To |
|-----------------|---------------|
| Technical user | Asks about APIs, integrations, data flows, system architecture |
| Non-technical user | Focuses on outcomes, avoids jargon, asks about team adoption |
| Budget-ready | Discusses build vs. buy, implementation options, ROI timeline |
| Budget-constrained | Focuses on quick wins, phased approaches, free/low-cost options |

---

### Input Methods

Users can respond via:
- **Voice recording** (auto-transcribed)
- **Text input** (typed directly)

---

### If "Needs Edit" is Clicked

The AI generates targeted follow-up questions based on what's missing:

| Data Gap | Follow-Up Question |
|----------|--------------------|
| Missing hours/time | "How much time does your team spend on this each week? Even a rough estimate helps." |
| Missing cost/budget | "Do you have a sense of what this is costing you currently?" |
| Missing stakeholders | "Who else on your team is affected by this issue?" |
| Missing tools | "What tools or systems are you currently using for this?" |
| Weak ROI confidence | "To calculate savings accurately: roughly how many hours per week does your team spend on this?" |
| Low severity flagged | "Is this actually causing significant problems, or more of a minor annoyance?" |

## Phase 3 - Synthesis (~15 min)

*"Final context for your report"*

| #  | Question | How They Answer | Required |
|----|----------|-----------------|----------|
| 1  | Who else needs to be involved in this decision? | Free text (e.g. "CEO, CFO, IT Manager") | No |
| 2  | What's your ideal timeline for making changes? | `Immediately (30 days)` / `This quarter` / `Next 6 months` / `Within a year` / `Just exploring` | Yes |
| 3  | Anything else we should know? | Free text | No |

Then: **"Generate My Report"** button.

---

## Quality Gate

The system enforces minimum data quality before allowing report generation:

| Requirement | Minimum |
|-------------|---------|
| Pain points discussed | At least 1 |
| Milestones generated | At least 1 |
| Messages per milestone | At least 4 |

If insufficient, the user sees specific gaps they need to fill.
